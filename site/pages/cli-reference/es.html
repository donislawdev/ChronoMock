Referencia CLI

chrono.exe es la parte de línea de comandos de Chrono Mock: inicia una aplicación en otra fecha y hora y calcula fechas de prueba, para scripts y pipelines de CI.

La referencia completa - cada opción, cada código de salida y la salida JSON - está en inglés, junto con el resto de la documentación. chrono --help muestra los mismos comandos en el propio programa.

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
