CLI संदर्भ

chrono.exe Chrono Mock का कमांड-लाइन हिस्सा है: यह किसी ऐप्लिकेशन को दूसरी तारीख और समय पर शुरू करता है और स्क्रिप्ट और CI पाइपलाइन के लिए टेस्ट तारीखें निकालता है।

पूरा संदर्भ - हर विकल्प, हर एग्ज़िट कोड और JSON आउटपुट - बाकी दस्तावेज़ों के साथ अंग्रेज़ी में है। chrono --help प्रोग्राम के अंदर भी यही कमांड दिखाता है।

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
पूरा संदर्भ (अंग्रेज़ी में) CLI और CI
