Referensi CLI

chrono.exe adalah sisi baris perintah Chrono Mock: menjalankan aplikasi pada tanggal dan waktu lain serta menghitung tanggal uji, untuk skrip dan pipeline CI.

Referensi lengkap - setiap opsi, setiap kode keluar, dan keluaran JSON - tersedia dalam bahasa Inggris, bersama dokumentasi lainnya. chrono --help menampilkan perintah yang sama di dalam program.

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
