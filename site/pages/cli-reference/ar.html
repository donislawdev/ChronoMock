مرجع CLI

chrono.exe هو واجهة سطر الأوامر في Chrono Mock: يشغّل تطبيقًا بتاريخ ووقت آخرين ويحسب تواريخ الاختبار للنصوص البرمجية ومسارات CI.

المرجع الكامل - كل خيار وكل رمز خروج ومخرجات JSON - متاح بالإنجليزية مع بقية الوثائق. ويعرض chrono --help الأوامر نفسها داخل البرنامج.

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
