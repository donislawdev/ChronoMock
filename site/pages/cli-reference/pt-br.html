Referência da CLI

O chrono.exe é o lado de linha de comando do Chrono Mock: ele inicia um aplicativo em outra data e hora e calcula datas de teste, para scripts e pipelines de CI.

A referência completa - cada opção, cada código de saída e a saída JSON - está em inglês, junto com o resto da documentação. O chrono --help mostra os mesmos comandos no próprio programa.

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
