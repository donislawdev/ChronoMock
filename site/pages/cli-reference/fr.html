Référence CLI

chrono.exe est le côté ligne de commande de Chrono Mock : il lance une application à une autre date et heure et calcule des dates de test, pour les scripts et les pipelines CI.

La référence complète - chaque option, chaque code de sortie et la sortie JSON - est en anglais, avec le reste de la documentation. chrono --help affiche les mêmes commandes dans le programme lui-même.

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
