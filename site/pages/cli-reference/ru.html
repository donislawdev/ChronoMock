Справочник CLI

chrono.exe - это командная строка Chrono Mock: она запускает приложение с другой датой и временем и вычисляет тестовые даты для скриптов и CI-конвейеров.

Полный справочник - каждый флаг, каждый код завершения и вывод JSON - на английском, вместе с остальной документацией. chrono --help показывает те же команды в самой программе.

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
