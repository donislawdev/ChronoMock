Wiersz poleceń

Każde polecenie chrono.exe i każda opcja, którą przyjmuje. Kody wyjścia mają osobną stronę.

Zanim zaczniesz

  • Dwa pliki chrono.exe. Paczka wiersza poleceń ma chrono.exe dla programów 64-bitowych i x86\chrono.exe dla 32-bitowych. Okno wybiera właściwy samo, wiersz poleceń nie. chrono run app.exe --dry-run mówi, którego potrzebuje dany program.
  • Datę i godzinę zapisuje się RRRR-MM-DDTGG:MM:SS, np. 2026-03-31T23:59:00, w strefie sesji, chyba że opcja mówi o UTC.
  • Krok to znak, liczba i jednostka: +1d, -2h, +3mo. m to minuty, a mo miesiące.
  • Pomoc jest też w programie: chrono --help dla wszystkich poleceń, chrono run --help dla jednego. Program odpowiada po angielsku.

Polecenia

{{cli_commands}}

chrono run

Uruchamia program, przestawia jego zegar i czeka, aż program się zamknie. Potem wypisuje raport, który mówi, czy data do programu dotarła, i kończy się kodem wyjścia, który mówi to samo skryptowi. 

# Start w danym momencie, zegar biegnie sześćdziesiąt razy szybciej
chrono run .\build\app.exe --at 2038-01-19T03:14:00 --mode x60

# Ostatni dzień tego miesiąca przez trzydzieści sekund, raport zapisany jako dowód
chrono run .\build\app.exe --preset month-end --ticks 30 --report dowod.txt

# Zobacz, jaka byłaby sesja, nic nie uruchamiając
chrono run .\build\app.exe --at +1y --dry-run
{{cli_options_run}}

chrono calc

Każda opcja to jeden krok, a kroki wykonują się w kolejności, w jakiej je wpiszesz. Wynik po każdym kroku jest wypisany, więc krok, który zrobił coś nieoczekiwanego, widać od razu: 

chrono calc --base 2026-01-31T09:30:00 --shift +1mo --snap eom --zone +01:00
Chrono Mock - date calculator
  base:    2026-01-31T09:30:00
  step 1:  shift +1 months  -> 2026-02-28T09:30:00
           ^ day clamped from 31 to 28 - that month is shorter
  step 2:  snap to end of month  -> 2026-02-28T23:59:59
  result:  2026-02-28T23:59:59
  ...

Po wyniku jest ten sam moment w kilkunastu formatach, dzień tygodnia, numer tygodnia, a z --calendar także to, czy to dzień roboczy.

chrono version i chrono license

chrono version wypisuje jeden wiersz, który skrypt może odczytać, np. chrono {{version}} (x64, protocol 1). chrono license wypisuje licencję, GPL-3.0, i to, co jest dołączone do programu.
