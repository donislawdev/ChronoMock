Довідник CLI

chrono.exe - це командний рядок Chrono Mock: він запускає застосунок з іншою датою й часом і обчислює тестові дати для скриптів і CI-конвеєрів.

Повний довідник - кожен прапорець, кожен код завершення й виведення JSON - англійською, разом з рештою документації. chrono --help показує ті самі команди в самій програмі.

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
