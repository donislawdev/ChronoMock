เอกสารอ้างอิง CLI

chrono.exe คือส่วนบรรทัดคำสั่งของ Chrono Mock ใช้เปิดแอปพลิเคชันด้วยวันที่และเวลาอื่น และคำนวณวันที่สำหรับทดสอบ สำหรับสคริปต์และไปป์ไลน์ CI

เอกสารอ้างอิงฉบับเต็ม ทั้งทุกตัวเลือก ทุกรหัสออก และผลลัพธ์ JSON เป็นภาษาอังกฤษเช่นเดียวกับเอกสารส่วนอื่น และ chrono --help ก็แสดงคำสั่งเดียวกันในตัวโปรแกรม

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
เอกสารอ้างอิงฉบับเต็ม (ภาษาอังกฤษ) CLI และ CI
