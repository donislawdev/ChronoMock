Reference CLI

chrono.exe je příkazová řádka Chrono Mock: spustí aplikaci s jiným datem a časem a počítá testovací data, pro skripty a CI pipeline.

Úplná reference - každý přepínač, každý návratový kód a výstup JSON - je v angličtině spolu se zbytkem dokumentace. chrono --help vypíše tytéž příkazy přímo v programu.

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
