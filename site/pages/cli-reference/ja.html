CLI リファレンス

chrono.exe は Chrono Mock のコマンドライン版です。アプリケーションを別の日付と時刻で起動し、スクリプトや CI パイプライン向けにテスト用の日付を計算します。

すべてのオプション、すべての終了コード、JSON 出力を含む完全なリファレンスは、ほかのドキュメントと同じく英語です。chrono --help でも同じコマンドをプログラム内で確認できます。

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
完全なリファレンス（英語） CLI と CI
