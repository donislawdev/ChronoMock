Referința CLI

chrono.exe este partea de linie de comandă a Chrono Mock: pornește o aplicație la altă dată și oră și calculează date de test, pentru scripturi și pipeline-uri CI.

Referința completă - fiecare opțiune, fiecare cod de ieșire și ieșirea JSON - este în engleză, împreună cu restul documentației. chrono --help afișează aceleași comenzi în program.

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
