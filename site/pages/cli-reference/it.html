Riferimento CLI

chrono.exe è il lato riga di comando di Chrono Mock: avvia un'applicazione in un'altra data e ora e calcola date di test, per script e pipeline CI.

Il riferimento completo - ogni opzione, ogni codice di uscita e l'output JSON - è in inglese, insieme al resto della documentazione. chrono --help mostra gli stessi comandi nel programma stesso.

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
