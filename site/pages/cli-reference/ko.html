CLI 레퍼런스

chrono.exe는 Chrono Mock의 명령줄 도구입니다. 애플리케이션을 다른 날짜와 시간으로 실행하고, 스크립트와 CI 파이프라인을 위한 테스트 날짜를 계산합니다.

모든 옵션, 모든 종료 코드, JSON 출력을 담은 전체 레퍼런스는 나머지 문서와 함께 영어로 되어 있습니다. chrono --help도 프로그램 안에서 같은 명령을 보여 줍니다.

chrono run <application> [options]
chrono calc [options]
chrono presets
chrono calendars
chrono version
chrono license
chrono --help
