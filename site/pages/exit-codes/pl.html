Kody wyjścia

Co znaczy kod na końcu każdego polecenia chrono - dla skryptu, który musi zdecydować, co dalej.

chrono run

Kod to werdykt sesji, a nie kod, którym zakończył się program. Program, który spokojnie przeszedł na prawdziwej dacie, wcale nie przetestował daty, a skrypt czytający tylko jego kod nigdy by tego nie zauważył. Ten kod nadal jest: w raporcie, w wierszu exited, i w --json.

{{exit_codes_run}}
  • 0, 10, 11 i 4 to werdykt: czy data dotarła do programu.
  • 8 też przychodzi po werdykcie, który jest wtedy na ekranie, ale nie w pliku.
  • 12 znaczy, że program odszedł, zanim dało się go ocenić.
  • Pozostałe znaczą, że przebieg tak daleko nie doszedł, więc nic nie mówią o programie.

W pipeline krok, który przechodzi tylko przy pełnym werdykcie, wygląda tak. Uzasadnienie i zastrzeżenia co do runnerów są na stronie CLI i CI. 

chrono run .\build\app.exe --at 2038-01-19T03:14:00 --ticks 20 --timeout 120 --report dowod.txt
if ($LASTEXITCODE -ne 0) { throw "chrono run ended with $LASTEXITCODE" }
