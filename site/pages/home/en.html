Why this exists

Testing anything date-dependent means moving time. Both usual options are bad.

Licence expiry, trial periods, subscription renewals, certificate validity, token lifetimes, month-end and year-end reports, interest accrual, reminders.

Option 1 - change the system clock

It breaks domain logon and Kerberos, invalidates TLS certificates so the browser stops working, confuses Windows Update, and makes every other application on the machine write wrong timestamps. On a domain-joined machine group policy usually blocks the change or reverts it minutes later, so the test is not even repeatable.

Option 2 - wait

Which means: do not test it. So the date-dependent cases get skipped, and "the licence never expires" ships to the customer.

What it does

One process moves through time. Everything else on the machine does not.

Any moment

A specific date and time, or a relative one - +30 days, -1 year.

Flowing, frozen or accelerated

Normal speed, a held clock, or a whole-number multiplier. x1440 turns a day into a minute.

Its own time zone

A fixed offset for that process only, while the system zone stays exactly where it was.

Child processes come along

Installers and launchers spawn children. Without that, the test covers half of what ran.

Jump mid-session

Forward or backward - including the backward jump a laptop makes after resyncing with a time server.

Electron and Chromium too

Through a different mechanism, because their clock lives in a sandboxed renderer where injection does not reach.

The part nobody else does

How do you know it worked?

With every other tool you do not. The application starts, shows some date, and you assume. But it can read the clock through a channel the tool never intercepted - from a server, from a database, through a runtime layer - and then "the test passed" means nothing at all.

Two minutes with it

A window for exploring, a command line for CI. The same engine behind both.

# Run an application as if it were the last second of 2027
chrono run "C:\apps\test.exe" --at 2027-12-31T23:59:59

# Watch a 30-day trial expire while you make coffee: x1440 is a day a minute
chrono run "C:\apps\test.exe" --mode x1440

# Use a named scenario instead of a date, and write the evidence to a file
chrono run "C:\apps\test.exe" --preset year-rollover --report session.txt
