Documentation

Chrono Mock starts one Windows application at a date and time you choose and leaves the clock of the computer alone. These pages show how to do that in the window and on the command line, and how to read what it tells you afterwards.

Where to start

  • The first time: Your first session goes through one in the window, from choosing the application to reading the result.
  • In a script or a pipeline: the CLI reference lists every command and option, Exit codes what a script can branch on and JSON output every field it can read. CLI and CI shows a whole pipeline.
  • When a session did not do what you expected: Reading the report says what each line means, and Troubleshooting what to do about it.
  • Before you run what you downloaded: Checking the download.
