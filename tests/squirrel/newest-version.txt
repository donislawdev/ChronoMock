# The version folders beside a Squirrel starter, and the one the starter starts ("-" for none).
# Read by crates/cli/src/squirrel.rs and by the window's mirror, gui/ChronoMock.App/Session/SquirrelStarter.cs,
# so the command line and the window start the same program. Precedence is Semantic Versioning 2.0.0
# (semver.org, item 11). Of equal versions the first named wins, as the starter keeps the first it finds.

# Build metadata does not count, so the first of equal versions stays
